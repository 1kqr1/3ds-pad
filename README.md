# 3DS Pad

Androidスマホを、Macで動いている3DSエミュレーター **Azahar** の「下画面＋ボタン」にするツールです。
ゲームはMacで動かしたまま、スマホに下画面とボタンを表示して、指でなぞったりボタンを押したりできます。

- 下画面のタッチ・なぞり（Macのマウスドラッグとして入力）
- スライドパッド・十字キー・A/B/X/Y・L/R・ZL/ZR・START/SELECT/HOME
- Azaharのキー割り当てを自動で読み取る（割り当てを変えていてもOK）
- Wi-Fi または USB で接続。QRコードを読むだけ
- スマホのホーム画面にアプリとして追加できる（全画面・横向き）

> **ゲームのデータ（ROM）やシステムファイルは同梱していません。** ご自身の3DSから吸い出したものをお使いください。

## 必要なもの

- macOS 13 以降（Apple Silicon 版を配布。Intel Mac は「ソースから起動」を使ってください）
- Azahar（https://azahar-emu.org/）
- Android スマホ（Chrome）

## はじめかた

### 1. アプリを入れる
1. [Releases](../../releases) から `3DS-Pad-…-mac-arm64.zip` をダウンロードして展開します。
2. `3DS Pad.app` を「アプリケーション」フォルダに入れます。
3. 初回は「開発元を確認できません」と出ます。
   **システム設定 → プライバシーとセキュリティ** の下の方にある「このまま開く」を押してください。

### 2. Macの許可
アプリの画面に「未許可」と出ている項目の「設定を開く」を押して、**3DS Pad** をオンにします。

| 許可 | 使い道 |
|---|---|
| 画面収録 | 下画面をスマホに送るため |
| アクセシビリティ | スマホのタッチ・ボタンをMacに入力するため |

許可を変えたら、3DS Pad を一度終了して開き直してください。

### 3. Azaharの設定
**表示 → 画面レイアウト → Separate Windows（別ウィンドウ）** にして、ゲームを起動します。
上画面と下画面が別のウィンドウになり、3DS Pad が下画面を自動で見つけます。
下画面ウィンドウを大きくするほど、スマホの映像がきれいになります。

### 4. スマホをつなぐ

**Wi-Fi（かんたん）**
1. スマホをMacと同じWi-Fiにつなぎます。
2. 3DS Pad で「Wi-Fi」を選び、表示されたQRコードをスマホのカメラで読み取ります。
3. Macで「受信接続を許可しますか？」と出たら「許可」を押します。

**USB（遅延が少ない・Wi-Fiでつながらないとき）**
1. スマホの **設定 → デバイス情報 → ソフトウェア情報** で「ビルド番号」を7回タップし、開発者向けオプションを出します。
2. 開発者向けオプションで **USBデバッグ** をオンにします。
3. USBでMacにつなぎ、スマホに出る「USBデバッグを許可しますか？」で許可します。
4. 3DS Pad で「USB」を選び、QRコードを読み取ります（「USB接続」が「接続中」になっていればOK）。

### 5. アプリとして追加（おすすめ）
スマホのChromeで開いたら、右上の「︙」→「ホーム画面に追加」→「インストール」。
次からはホーム画面のアイコンから全画面・横向きで開けます。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| スマホでページが開かない（Wi-Fi） | 同じWi-Fiか確認。Macの **ネットワーク → ファイアウォール** で 3DS Pad を許可。ルーターが端末同士の通信を禁止していることもあるので、その場合はUSBで |
| 「Azaharの下画面: 見つかりません」 | Azaharを「Separate Windows」にしてゲームを起動しているか確認 |
| ボタンが効かない | 3DS Pad 右側の「キー割り当て」に警告が出ていないか確認。コントローラーに割り当てたボタンはスマホから押せません（キーボードに割り当ててください） |
| タッチの位置がずれる | 下画面ウィンドウの大きさを変えると直ることがあります |
| アップデート後に許可が外れた | もう一度「画面収録」「アクセシビリティ」で 3DS Pad をオンにしてください |

## しくみ

```
スマホ（Chrome）  ──WebSocket──▶  3DS Pad（Mac）  ──キー入力・マウス操作──▶  Azahar
        ◀──── 下画面の映像（JPEG） ────  画面キャプチャ
```

- 接続用URLにはランダムな接続コードが入っていて、知らない人は操作できません。「接続コードを作り直す」で変更できます。
- 設定は `~/Library/Application Support/3DSPad/settings.json` に保存されます（`port` `fps` `quality` を変えられます）。

## 開発

```bash
# ビルドせずに起動
./ソースから起動.command          # ウィンドウあり
./ソースから起動.command --headless  # ターミナルだけ

# テスト
python3 -m pytest -q tests

# .app をビルド（dist/ に出力）
./scripts/build_mac.sh
```

`v1.0.0` のようなタグを push すると、GitHub Actions が `.app` をビルドしてリリースに添付します。
